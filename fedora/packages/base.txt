  # placed correctly: upstream migration 1794518371.sh adds it for
  # bin/omarchy-tray-context-menu, which reads Xwayland's monitor layout to
  # open a Wine app's own tray menu at the pointer.

# xsetroot (Arch: xorg-xsetroot) is no longer installed: upstream dropped it
# together with default/hypr/startup-cursor.lua, the only caller. That script
# started Hyprland with a blank cursor theme and then reset the X root cursor,
# which is what X11/XWayland apps (e.g. scid Community) inherited. Without it
# nothing hides the root cursor, so no reset is needed. Existing installs keep
# the package (it is not in retired-packages.conf, same as lazydocker), and it
# stays available as a manual fix: `xsetroot -cursor_name left_ptr`.
